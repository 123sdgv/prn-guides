## What This Is

这是一份持续更新的个人写作方法论合集。

核心关注点是：**异性恋关系（BG/GB）中，性别、权力与欲望是如何在小说书写中被构建和表达的。**

不是教条，不是规范，是思考工具。

写畸形恋爱也好，写成熟关系也好，清楚底层逻辑，才能有意识地打破它——或者有意识地维护它。
